# SarprasHub - WebApp

Aplikasi manajemen sarana dan prasarana (Sarpras) menggunakan tema UI Claymorphism. 
Dibuat dengan React, Vite, Tailwind CSS, dan Firebase.

## Instalasi
1. `npm install`
2. Duplicate `.env.example` menjadi `.env` dan isi kredensial Firebase Anda.
3. `npm run dev`

## Deployment
Siap di-deploy menggunakan Vercel. Pastikan Environment Variables dimasukkan di dashboard Vercel.
